
# Customer Churn Prediction — End-to-End MLOps

A machine learning project for predicting customer churn using Python, Scikit-learn, MLflow, FastAPI, Docker, and GitHub Actions.

## Project Objectives

- Explore and preprocess customer churn data.
- Train and evaluate machine learning classification models.
- Track experiments and model performance with MLflow.
- Build a prediction API using FastAPI.
- Containerize the application with Docker.
- Implement automated testing and CI/CD.
- Deploy and monitor the model.

## Technology Stack

- Python 3.12
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- MLflow
- FastAPI (planned)
- Docker (planned)
- GitHub Actions (planned)
